## TIER 3

### Q43 — **C — The maternal mortality rate is lower in District Y; the ratio is unchanged**
**Topic:** Maternal mortality rate vs ratio
**Source:** PDF p.104 | E1
**Closest distractor:** A — "ratio lower"
**Concept link:** MMRate denominator = women aged 15–49 (p.104) + MMRatio denominator = live births (p.104) -> only the rate falls
The maternal mortality rate uses women aged 15–49 as its denominator, and the ratio uses live births. Doubling only the number of women lowers the rate and leaves the ratio unchanged.

### Q45 — **B — Epidemic**

An epidemic is occurrence clearly above the normal expectation. Where the expected number is zero, a single wild poliovirus case is an epidemic.
