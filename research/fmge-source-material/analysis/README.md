# FMGE pattern analysis

This directory contains derived research, not source papers.

Planned outputs for the primary 2022-2026 study:

- `session-summary.csv` - one row per verified sitting
- `question-patterns.csv` - question-level classifications using the schema in `../extracted/question-schema.md`
- `five-year-pattern-report.md` - aggregate findings and trend changes
- `prompt-calibration.md` - evidence-backed rules for Tier 1 / Tier 2 / Tier 3 question generation

Pattern calculations should explicitly state their denominator and exclude samples, mirrors and incomplete sources when a whole-paper percentage would otherwise be misleading.
